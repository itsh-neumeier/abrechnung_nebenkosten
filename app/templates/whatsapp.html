WhatsApp-Versand

Abrechnungen können per WhatsApp verschickt werden – direkt über die offizielle WhatsApp Business Cloud API von Meta oder über n8n (Webhook, dort z. B. Evolution API oder Cloud API). Welche Partei WhatsApp bekommt, stellst du unter Parteien ein (Nummer + Versand „WhatsApp“ oder „E-Mail und WhatsApp“). Der Versand läuft über dieselben Knöpfe wie die E-Mail („senden“ / „Alle senden“ bzw. automatisch beim Abschließen).

Einrichtung bei Meta
  1. Meta-Business-Konto anlegen (business.facebook.com) und unter developers.facebook.com eine App vom Typ „Business“ mit dem Produkt WhatsApp erstellen. Eine eigene Telefonnummer hinzufügen und verifizieren (die Nummer darf nicht gleichzeitig in der normalen WhatsApp-App genutzt werden).
  2. Im Business Manager unter Systembenutzer einen Benutzer anlegen, ihm die App und das WhatsApp-Konto zuweisen und ein dauerhaftes Token mit whatsapp_business_messaging und whatsapp_business_management erzeugen.
  3. In Portainer / .env eintragen: WA_TOKEN (Token), WA_PHONE_NUMBER_ID (WhatsApp → API-Setup → Telefonnummern-ID), WA_APP_SECRET (App-Einstellungen → Allgemein → App-Geheimcode). Stack neu deployen.
  4. Nachrichtenvorlage im WhatsApp Manager anlegen: Name {{ st.wa_template_name }}, Sprache {{ st.wa_template_lang }}, Kategorie Utility, Kopfzeile Dokument, Text z. B.
    „Hallo {{ '{{1}}' }}, anbei Ihre Nebenkostenabrechnung für {{ '{{2}}' }}. Betrag: {{ '{{3}}' }}. Viele Grüße“
    ({{ '{{1}}' }} Name, {{ '{{2}}' }} Zeitraum, {{ '{{3}}' }} Betrag). Rechnungen gehen außerhalb des 24-Stunden-Fensters raus – ohne genehmigte Vorlage nimmt Meta sie nicht an.
  5. Optional Zustellstatus (gesendet → zugestellt → gelesen): in der App unter WhatsApp → Konfiguration → Webhook die Rückruf-URL {% if meta_webhook %}{{ meta_webhook }}{% else %}https://<APP_BASE_URL>/api/whatsapp/webhook (APP_BASE_URL setzen – muss von außen per HTTPS erreichbar sein){% endif %} und das Prüf-Token {{ verify_token }} eintragen, dann das Feld messages abonnieren. Ohne Webhook zeigt die Abrechnung „gesendet“.
  6. Oben „direkt – WhatsApp Business Cloud API“ wählen, speichern und unten „Test senden“.

Kosten: Meta berechnet Vorlagen-Nachrichten der Kategorie Utility pro Nachricht (in Deutschland im Cent-Bereich, aktuelle Preise in der Meta-Dokumentation). Testnummern von Meta senden nur an bis zu 5 freigeschaltete Empfänger.

Über n8n {% if st.wa_mode != 'native' %}aktiv{% endif %}

  1. Unten den Flow für deine WhatsApp-Variante kopieren und in n8n in einen leeren Workflow einfügen (Strg+V).
  2. Im Knoten Konfiguration Zugangsdaten eintragen, Workflow speichern und aktivieren.
  3. Im Knoten Webhook die Production URL kopieren und hier eintragen, dann „Test senden“.
